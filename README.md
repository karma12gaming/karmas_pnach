# Read Me

Karma's collection of .pnach files updated to work with PCSX2 1.7+

## How to Download

- Go to the file you want
- Click the 'Download Raw File' button on the right side.

## How to Install

- Download the pnach file
- Move the pnach file into the PCSX2 'cheats' folder usually located at 'C:\Users\USERNAME\Documents\PCSX2\cheats'
- Do not change the file name.
- v1.6 is not supported
