# readme

Karma's collection of `.pnach` files updated to work with PCSX2 1.7+ & 2.0+

## How to Download

- Go to the file you want. (Check [Files](#files))
- Click the 'Download Raw File' button on the right side.

## How to Install

- Download the pnach file
- Move the pnach file into the PCSX2 `cheats` folder.  
To locate the cheats folder: Open PCSX2. Go to Settings > Folders > Cheats Directory > Open...
- Do not change the file name. (File names must be correctly formatted by `Serial_CRC.pnach`)
- Other versions of the game are not supported. (Serial & CRC must match.)
- PCSX2 v1.6 is not supported.
