# readme

Karma's collection of .pnach files updated to work with PCSX2 v1.7+ and v2.0+  
<small>PCSX2 v1.6 is not supported!</small>

## How to Download

- Go to the file you want. (Check [Files](#files))
- Click the `Download Raw File` icon on the right side.

## How to Install

- Download the .pnach file
- Move the .pnach file into the PCSX2 cheats folder.
- To locate the cheats folder:
  - Open PCSX2.
  - Go to `Settings > Folders > Cheats Directory > Open...`
- Do not change the file name. <small>  
  (File names must be in the correct format. Example:`Serial_CRC.pnach`)</small>
- Other versions of the game are not supported. <small> (Serial & CRC must match.)</small>

## How to Enable

- Open PCSX2.
- Right Click Game > Properties
- Select Cheats
- Check Enable Cheats
- Toggle each cheat you want enabled.

## Use At Your Own Risk

**Activating cheats (patches) can cause unpredictable behavior, crashing,
soft-locks, or broken saved games. Use cheats at your own risk, the PCSX2
team will provide no support for users who have enabled cheats.**
